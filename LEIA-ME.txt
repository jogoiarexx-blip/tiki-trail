TIKI TRAIL — VERSÃO ORGANIZADA + PWA

ESTRUTURA
index.html                       Entrada mínima do jogo
manifest.webmanifest             Metadados da instalação PWA
sw.js                            Service Worker / cache offline
offline.html                     Fallback de navegação offline
assets/css/game.css              Estilos compilados do jogo
assets/js/game.bundle.js         Bundle compilado atual do jogo
assets/js/pwa.js                 Instalação PWA e registro do Service Worker
assets/icons/icon-192.png        Ícone PWA 192x192
assets/icons/icon-512.png        Ícone PWA 512x512

IMPORTANTE
- O jogo continua abrindo por index.html com dois cliques, mas Service Worker e instalação PWA NÃO funcionam em file://.
- Para instalar e testar offline, publique em HTTPS (GitHub Pages, Render, Netlify etc.) ou use localhost.
- O progresso atual continua usando o armazenamento local do navegador, pois a lógica original do jogo foi preservada.

TESTE LOCAL COM PWA
Se tiver Python instalado, abra um terminal nesta pasta e execute:
  python -m http.server 8080
Depois abra:
  http://localhost:8080

SOBRE A MODULARIZAÇÃO
O arquivo original tiki-trail.js já veio como bundle React compilado/minificado (~2 MB). Ele foi isolado em assets/js/game.bundle.js sem alteração para reduzir risco de quebrar o jogo. Para separar internamente em player.js, fases.js, audio.js, input.js etc., é necessário o código-fonte anterior ao build/bundle.


CORRECAO v3 - FILE:// E WEBGL
- O sprite 32-bit foi incorporado ao bundle como data URI para evitar canvas WebGL contaminado ao abrir index.html com dois cliques.
- Em file:// o jogo roda sem registrar Service Worker/manifest.
- Instalacao PWA e cache offline continuam habilitados quando publicado em localhost, GitHub Pages, Render ou outro host HTTP/HTTPS.
- Cache atualizado para tiki-trail-v3.
