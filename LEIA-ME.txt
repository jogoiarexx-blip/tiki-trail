TIKI TRAIL

Projeto web/PWA de plataforma 2D tropical, organizado para funcionar diretamente no GitHub Pages.

ESTRUTURA PRINCIPAL
- index.html na raiz
- assets/css/game.css
- assets/js/game.bundle.js
- assets/js/render-fix-v7.js
- assets/js/pwa.js
- assets/sprites/player-32bit.webp
- assets/sprites/integrated/ com os sprite sheets atuais
- assets/icons/
- manifest.webmanifest
- sw.js
- offline.html

ATUALIZACAO v7
- Corrigido o desenho das plataformas para separar visual e colisao.
- O sprite de piso nao e mais esticado pela altura inteira dos colliders.
- O corpo das plataformas usa novamente o renderer procedural original e o sprite funciona apenas como acabamento da superficie.
- Armadilhas de espinhos agora usam o mesmo Y fisico da colisao e crescem para cima.
- O personagem teve ajuste visual de 4 px para os pes coincidirem melhor com a superficie fisica.
- Guard e Lantern Hunter tiveram o ponto visual de apoio no chao corrigido.
- Frames de sprites duplicados foram removidos da publicacao; permanecem apenas os sprite sheets usados pelo jogo.
- Cache PWA atualizado para tiki-trail-v7.

GITHUB PAGES
